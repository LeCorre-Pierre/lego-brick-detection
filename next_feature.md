# Next Feature: Annotation Tool — What Was Built

## Summary

A full annotation capture system was integrated directly into the app to collect training data for a per-set YOLO model.

## What Was Implemented

### Backend — `src/annotation/`

| Module | Purpose |
|--------|---------|
| `models.py` | `BrickClass`, `Annotation`, `AnnotatedImage`, `Dataset`, `AnnotationProject` dataclasses |
| `yolo_format.py` | `YoloFormatter`: pixel↔normalized conversions, read/write label files |
| `dataset_builder.py` | `DatasetBuilder`: create datasets, split train/val, export YOLO format, validate |
| `annotation_manager.py` | `AnnotationManager`: CRUD on annotations, navigation, JSON save/load |
| `capture_manager.py` | `CaptureManager`: save frames as JPEG + YOLO label, auto-detect bbox, session management, `data.yaml` generation |

### GUI — `src/gui/annotation_panel.py`

Compact `QWidget` panel inserted between `DetectionPanel` and the video/brick-list area.

- Toggle button enables annotation mode (red = ON, grey = OFF)
- Active class synced with `BrickListWidget.brick_selected` signal
- **Space bar** captures the current frame (handled via `MainWindow.keyPressEvent`)
- Auto-bbox checkbox runs `ContourAnalyzer` to get bounding rect automatically
- Counter label shows captures per part number

### `src/gui/main_window.py` changes

- Imports `AnnotationPanel` and `CaptureManager`
- Inserts `annotation_panel` in layout
- Connects `brick_list_widget.brick_selected → annotation_panel.set_active_class`
- Connects `annotation_panel.capture_requested → _on_capture_requested`
- `_on_capture_requested`: grabs frame, runs auto-bbox if enabled, saves frame, updates counter
- `_init_capture_manager(lego_set)`: creates `CaptureManager` at `datasets/lego_set_<id>/` when set is loaded
- `keyPressEvent`: Space → `annotation_panel.trigger_capture_if_active()`

## Dataset Structure

```
datasets/
  lego_set_<set_number>/
    data.yaml                    ← generated by CaptureManager.generate_data_yaml()
    session_YYYYMMDD_HHMM/
      images/   ← JPEG frames
      labels/   ← YOLO .txt labels (one per captured frame with bbox)
```
